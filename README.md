### Estrutura Básica da POO
- **Classe** → molde para criação de objetos
- **Atributo** → características do objeto
- **Método** → ações que o objeto executa
- **Objeto e Mensagem** → instância da classe e comunicação entre objetos

### Relações: Herança, Associação e Interface
- **Herança** → reutilização de código entre classes
- **Upcast e Downcast** → conversão entre tipos da hierarquia
- **Polimorfismo e Sobrescrita** → mesmo método com comportamentos diferentes
- **Associação** → relacionamento entre classes
- **Interface** → contrato que define comportamentos

### Organização de Pacotes e Visibilidades
- **Pacotes** → organização e agrupamento de classes
- **Visibilidades** → public, private, protected e default
